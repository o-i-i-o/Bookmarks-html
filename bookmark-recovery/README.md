# [Chrome Bookmarks to html ](https://rongjiecomputer.github.io/chrome/bookmark-recovery/)

这是一个用 JavaScript 写的 Chrome 本地书签文件 (`Bookmarks` or `Bookmarks.bak`) 转为各种浏览器可以直接导入的html文件的工具。
